# Expense claim review

1. Match each claimed line to a receipt: date, merchant and amount.
2. Check the category limits in the expense policy for the employee's level.
3. Flag duplicates, missing receipts and personal items; never approve a claim
   without a receipt for every line.
4. Report approved, rejected and flagged lines with the reason for each.
